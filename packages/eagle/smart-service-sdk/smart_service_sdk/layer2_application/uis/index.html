Smart Service SDK

API console for search and retrieval demos.

Use these pages to try the current `search`, `similarity`, `material-sds-analysis`, and runtime configuration APIs with sample payloads and inline JSON responses. The UI talks directly to the live `/api/v1/...` endpoints in this app.

Search demo

Run `POST /api/v1/search` with fielded payloads and fuzzy rules.

/api/v1/ui/search

Similarity demo

Explore vector and graph-backed retrieval with `POST /api/v1/similarity`.

/api/v1/ui/similarity

Config demo

Load and update both runtime config surfaces from one page.

/api/v1/ui/config

Material SDS demo

Submit one or many materials to `POST /api/v1/material-sds-analysis`.

/api/v1/ui/material-sds-analysis

Material Group demo

Recommend Material Group values from `POST /api/v1/similarity` evidence.

/api/v1/ui/material-group-recommendation

Buyer demo

Recommend Buyer or Purchasing Group values from `POST /api/v1/similarity` evidence.

/api/v1/ui/buyer-recommendation

Included API routes

  • `POST /api/v1/search`
  • `POST /api/v1/similarity`
  • `POST /api/v1/material-sds-analysis`
  • `GET /api/v1/search/config` and `PUT /api/v1/search/config`
  • `GET /api/v1/similarity/config` and `PUT /api/v1/similarity/config`
  • `GET /api/v1/ui/material-group-recommendation`
  • `GET /api/v1/ui/buyer-recommendation`

Good to know

These pages are intentionally lightweight: plain HTML, embedded CSS, and small `fetch` helpers so the showcase stays close to the backend and easy to extend.
