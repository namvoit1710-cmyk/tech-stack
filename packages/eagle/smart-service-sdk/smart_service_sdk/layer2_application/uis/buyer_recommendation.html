Buyer recommendation

This demo uses Plant, Division, Material Group, and optional material context to query historically similar records, then derives Buyer or Purchasing Group recommendations in the browser from similarity evidence. Confidence is inferred from retrieval evidence and historical indexed patterns, not from a trained model probability.

Plant, Division, and Material Group are required because buyer routing should follow these business signals.

This page is for Buyer/Purchasing Group recommendation only. It does not introduce workflow routing or approval logic, and it depends on buyer-related fields being present in similarity candidate metadata.
